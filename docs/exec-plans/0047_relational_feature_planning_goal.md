# Relational Feature Planning Goal

## Goal

Implement Relational Feature Planning v1 so Home Credit-style multi-table imports produce artifact-backed, train-fold-safe feature planning context without hard-coding an executable recipe.

## Inputs Reviewed

- `apps/backend/tabular_harness/services/benchmarks.py`
- `apps/backend/tabular_harness/services/agent_task_planner.py`
- `apps/backend/tabular_harness/services/agent_context.py`
- `apps/backend/tabular_harness/services/approach.py`
- `schemas/agent_context_pack.schema.json`
- Existing Home Credit fixture/import and relational catalog integration tests.

## Implementation Plan

- Add `POST /api/projects/{project_id}/features/relational-plan`.
- Require an existing `relational_catalog` artifact.
- Read benchmark scenario/source context, collection plan, quality context, EvaluationSpec, and SplitManifest when available.
- Generate `relational_feature_plan`, `relational_feature_report`, and `visualization_spec` artifacts.
- Create Report, Evidence, and Lineage records.
- Include primary/supporting table coverage, inferred join keys, aggregation candidates, point-in-time requirements, leakage/prediction-time risks, deferred AgentTask questions, recommended Skill/FeatureRecipe references, and artifact expectations.
- Propagate the latest relational feature plan into AgentTaskContracts, ResearchPlans, ResearchBriefs, Ideas, and AgentContextPacks.
- Add Data tab generation and preview/download.

## Technical Stack

- FastAPI synchronous MVP job endpoint.
- Existing RelationalCatalog JSON artifacts generated by benchmark import.
- SQLAlchemy model records for Artifact, Report, Evidence, VisualizationSpec, Job, and LineageEdge.
- React Data tab using existing artifact preview/download APIs.

## Implemented Scope

- RelationalFeaturePlan service and endpoint.
- Candidate numeric and categorical aggregation families derived from inferred primary/supporting table relationships.
- Fold-safety, SplitManifest, point-in-time, and prediction-time availability guardrails.
- Risk register and deferred AgentTask questions.
- Contract/context propagation for planner-generated AgentTaskContracts and Idea AgentContextPacks.
- Home Credit tiny integration test verifying plan generation and handoff.

## Deferred Scope

- Executing relational joins or aggregations.
- Persisting a runnable FeatureRecipe implementation.
- Full point-in-time joining for temporal supporting tables.
- Automatic scenario comparison between primary-only and relational feature sets.
- UI visualization beyond the existing stage-status artifact preview.

## Risks And Open Decisions

- Join relationships are inferred from names/cardinality and need semantic confirmation.
- Aggregation candidates can be useful but unsafe without SplitManifest-aware fitting and prediction-time availability review.
- Home Credit real-data performance claims must wait for confirmed relational FeatureRecipes, approved evaluation, and leakage checks.
