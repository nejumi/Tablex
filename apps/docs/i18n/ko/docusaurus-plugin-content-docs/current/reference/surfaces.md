# 제품 화면

무엇을 하고 싶은지는 알지만 어디에 있는지 모를 때 이 페이지를 사용하세요.

| 화면 | 용도 |
| --- | --- |
| Home | 현재 프로젝트 이야기, 다음 action, Agent Chat, Research Plan, 중요한 signals. |
| Data | Uploads, primary table, objective setup, dataset profiles, relation evidence. |
| Insight | 사람이 읽을 수 있는 reports, research findings, curated output queues. |
| Evaluation | Metric and split candidates, approval state, evaluation boundaries. |
| Leaderboard | Model comparison, diagnostics, prediction pipeline actions, pilot entry points. |
| Notebooks | Native marimo notebooks와 readiness state. |
| Assets | 등록된 모든 outputs와 artifacts의 정본 인벤토리. |
| Codex Console | 필요 시 raw execution transcript와 direct runner interaction. |
| Jobs | Background work와 operational activity. |

## 대부분 프로젝트의 읽는 순서

Home에서 시작한 뒤 첫 추천 Notebook 또는 report를 여세요. Model score가 나타나면 Evaluation으로 이동합니다. Leaderboard에서 model을 비교하고 prediction을 실행합니다. 모든 파일을 감사해야 할 때 Assets를 사용하세요.
