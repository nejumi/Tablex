# 画面一覧

何をしたいかは分かるが場所が分からない時に使います。

| 画面 | 使いどころ |
| --- | --- |
| Home | Projectの現状、次の一手、Agent Chat、Research Plan、重要シグナル。 |
| Data | アップロード、主表、目的、dataset profile、関係根拠。 |
| Insight | 人間向けレポート、調査、読むべき成果物。 |
| Evaluation | 指標・分割候補、承認状態、評価境界。 |
| Leaderboard | モデル比較、診断、予測pipeline、仮運用入口。 |
| Notebooks | native marimo Notebookと状態。 |
| Assets | 登録済み成果物の全在庫。 |
| Codex Console | 実行記録と必要時の直接操作。 |
| Jobs | background workと運用activity。 |

## 多くのProjectの読む順序

Homeから始め、推奨されたNotebookまたはレポートを開きます。モデルスコアが出たらEvaluationへ進み、Leaderboardで比較・予測します。全ファイル監査にはAssetsを使います。
