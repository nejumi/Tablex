# Assets、レポート、Notebook

Tablexは成果物をAssetとして保存します。Data、Insight、Leaderboard、Home、Assetsなど、意味のある文脈から同じ成果物を開けるようにします。

## Assets

Assetsは全成果物の正典リストです。アップロードデータ、profile、レポート、Notebook、モデル結果、予測パイプライン、図、manifest、検証出力が含まれます。

全体検索や監査にはAssetsを使います。何を読みたいか分かっている時は、Home、Insight、Data、Leaderboardの文脈リンクから開きます。

## レポート

レポートは人間が読むための成果物です。意思決定、要約、出典付き調査、モデル比較、Projectの引き渡しに向いています。

## native marimo Notebook

Notebook sourceが記録の正本です。Tablexはnative marimoを製品内で開き、分析を人間にもAgentにも再利用可能な資産として残します。

Notebookが失敗した場合は失敗を表示し、Agentにsourceを修復させます。静的HTMLで失敗を隠すべきではありません。

## スクリーンショットと図

Notebook内の図は分布、誤差、特徴量、診断を理解する助けになります。このドキュメントのスクリーンショットはUI説明用です。UIが固まったらplaceholderを差し替えてください。
