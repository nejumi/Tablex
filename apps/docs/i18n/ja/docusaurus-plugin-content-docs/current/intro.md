# Tablexドキュメント

Tablexは、表データ予測プロジェクトのためのagentic workbenchです。データサイエンスAgentが分析やモデリングを進める一方で、Tablexはデータ、目的、評価契約、Notebook、モデル結果、予測パイプライン、アセット、運用フィードバックを結び付けて見える状態に保ちます。

![Tablex Home workspace](/img/screenshots/home-workspace-placeholder.svg)

## Tablexが向いている場面

Tablexは「CSVを1つアップロードしてモデルを作る」だけでは済まない表データ課題に向いています。複数テーブル、行粒度の不確実性、遅れて届く実測値、派生ターゲット、リークリスク、外部調査、評価設計の人間判断などを扱えます。

## 基本の流れ

1. 1つ以上のデータファイルをアップロードします。
2. 目的を決めるか、データ理解後まで保留します。
3. Full Autoで、データ理解、Notebook作成、調査、評価提案、モデル学習、成果物登録を進めます。
4. Notebook、レポート、Leaderboard、Assetsを確認します。
5. ターゲットを含まない入力で予測し、実測値が届いたら仮運用評価を行います。
6. 新しい根拠を同じProjectへ戻し、Agentが監査、修復、改善できるようにします。

## UIの読み方

- Home: 現在のProjectの物語、Agent Chat、Research Plan、次の推奨アクション。
- Data: アップロード、主表、目的、profile。
- Insight: 読むためのレポート、調査、成果物。
- Evaluation: 指標と分割の候補。
- Leaderboard: モデル比較、診断、予測、仮運用。
- Assets: ファイル、Notebook、レポート、パイプライン、根拠の全在庫。
