# 产品界面

当你知道想做什么但不确定在哪里操作时，可以使用本页。

| 界面 | 用途 |
| --- | --- |
| Home | 当前项目故事、下一步操作、Agent Chat、Research Plan 和重要信号。 |
| Data | 上传、主表、目标设置、数据集 profile 和关系证据。 |
| Insight | 人类可读报告、调研发现和经过整理的输出队列。 |
| Evaluation | 指标和切分候选、批准状态和评估边界。 |
| Leaderboard | 模型比较、诊断、预测 pipeline 操作和试运行入口。 |
| Notebooks | Native marimo Notebook 及其准备状态。 |
| Assets | 所有已注册输出和 artifact 的统一清单。 |
| Codex Console | 需要时查看原始执行 transcript，并直接与 runner 交互。 |
| Jobs | 后台工作和运行活动。 |

## 大多数项目的阅读顺序

从 Home 开始，然后打开第一个推荐的 Notebook 或报告。模型分数出现后再进入 Evaluation。使用 Leaderboard 比较模型并运行预测。需要审计所有文件时使用 Assets。
