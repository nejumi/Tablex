# Tablex 文档

Tablex 是面向表格预测项目的智能体式工作台。它让数据科学智能体处理数据，同时由产品侧保持项目状态清晰：数据、目标、评估契约、Notebook、模型结果、预测流水线、资产和运营反馈都会相互链接。

![显示 Full Auto、Research Plan 和证据的 Tablex Home](/img/screenshots/home-workspace.png)

## Tablex 适合什么场景

当一个表格项目不只是“上传 CSV 然后训练模型”时，Tablex 会很有用。项目可能包含多张表、不确定的行粒度、延迟到来的结果、派生目标、泄漏风险、外部调研，以及人类对评估方式的判断。Tablex 让这些活动部件保持可见，同时由 Codex 或其他智能体对它们进行推理。

## 主循环

1. 上传一个或多个数据文件。
2. 决定目标，或者先暂缓目标设定。
3. 让 Full Auto 检查数据、创建 Notebook、提出评估方案、训练基线，并注册模型结果。
4. 在产品 UI 中查看 Notebook、报告、排行榜和资产。
5. 当有不含目标值的输入或后续实际结果时，运行预测批次或试运行验证。
6. 将新的证据反馈到同一个项目中，让智能体审计、修复或改进工作。

## 如何阅读界面

Tablex 有几个主要界面：

- Home：当前项目故事、Agent Chat、Research Plan 和推荐的下一步。
- Data：上传的数据集、主表选择、目标设定和 profile。
- Insight：可读报告、调研发现和面向人的输出。
- Evaluation：候选指标和数据切分设计。
- Leaderboard：模型运行、证据、诊断、预测和试运行操作。
- Assets：文件、Notebook、报告、流水线和证据的统一资产清单。

Agent workspace 将面向人的进展和上下文操作放在一起，同时保留 Codex Console 以便检查底层执行记录。
