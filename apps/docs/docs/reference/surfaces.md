# Product surfaces

Use this page when you know what you want to do but are not sure where it lives.

| Surface | Use it for |
| --- | --- |
| Home | Current project story, next action, Agent Chat, Research Plan, and important signals. |
| Data | Uploads, primary table, objective setup, dataset profiles, and relation evidence. |
| Insight | Human-readable reports, research findings, and curated output queues. |
| Evaluation | Metric and split candidates, approval state, and evaluation boundaries. |
| Leaderboard | Model comparison, diagnostics, prediction pipeline actions, and pilot entry points. |
| Notebooks | Native marimo notebooks and their readiness state. |
| Assets | Canonical inventory of all registered outputs and artifacts. |
| Codex Console | Raw execution transcript and direct runner interaction when needed. |
| Jobs | Background work and operational activity. |

## Reading order for most projects

Start with Home, then open the first recommended notebook or report. Move to Evaluation when model scores appear. Use Leaderboard to compare models and run prediction. Use Assets when you need to audit every file.
